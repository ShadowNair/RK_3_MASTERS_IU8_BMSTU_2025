## Описание ##

T Monitoring Pro 🚀 — это интерактивный дашборд для мониторинга ИТ-инфраструктуры и анализа веб-логов в реальном времени!

Представьте: все ваши серверы, метрики и логи — в одном месте, с красивой тёмной темой 🌓, прогресс-барами 📊 и умной аналитикой — без сложных настроек!

🔹 Что умеет наш дашборд?
✅ Системные метрики — CPU, RAM, диск, сеть для каждого сервера
✅ Цветовая индикация — зелёный 🟢 (healthy), оранжевый 🟠 (warning), красный 🔴 (critical)
✅ Глубокий анализ логов — фильтр по серверам, статусам, эндпоинтам и даже поиску по тексту 🔍
✅ Корреляция данных — автоматически находит связи: например, высокая загрузка CPU → всплеск 5xx-ошибок 📈
✅ PDF-отчёты 📄 — одним кликом сгенерируйте отчёт об инцидентах и рекомендациях!
✅ Готов к работе "из коробки" — данные генерируются автоматически при первом запуске! 🎁

## 🎯Для кого это? ##
- DevOps-инженерам и SRE, уставшим переключаться между Grafana и Kibana
- Разработчикам, которые хотят понимать, как их сервисы ведут себя в продакшене
- Студентам и исследователям — как пример современного аналитического дашборда на Python

Python • Streamlit • Pandas • NumPy • Plotly • FPDF

# Начинаем работу #
## Запуск программы ##
1. Создайте окружение
```
python3 venv myenv
```
2. Зайдите в окружение
```
source ./myenv/bin/activate
```
3. Установите зависимости, они расположены в requirements.txt:
```
# Core
streamlit==1.40.0
pandas==2.2.3
numpy==2.1.3

# Visualization
plotly==5.24.1
statsmodels==0.14.4

# PDF Report Generation
fpdf==1.7.2
```
Команда:
```
pip install -r requirements.txt
```
4. Для запуска самого сервера:
```
streamlit run ./main.py
```
5. (Опционально)Вам в консоли при первом запуске в консоли будет следующий вывод:
```
   👋 Welcome to Streamlit!

      If you’d like to receive helpful onboarding emails, news, offers, promotions,
      and the occasional swag, please enter your email address below. Otherwise,
      leave this field blank.
```
Не беспокойтесь, это можно спокойно пропустить нажав клавишу: Enter
# Поздравляю с запуском🎉🎊 #
# Взаимодействие с сайтом #
После запуска приложения вы попадаете на главную страницу дашборда IT Monitoring Pro — современный dark-интерфейс с боковым меню и четырьмя основными модулями. Вот как с ним работать:

## Навигация (боковое меню) ##
В левой части экрана — боковая панель с переключателями:

- Системные метрики — мониторинг загрузки серверов
- Анализ логов — исследование веб-запросов и ошибок
- Интеграционная аналитика — корреляция метрик и логов
- О проекте — краткая справка
- Просто кликните на нужный пункт — контент обновится мгновенно.

## Системные метрики ##
- Выберите нужные серверы, диапазон дат и пороговые значения CPU/RAM.
- В секции «Текущее состояние» вы увидите карточки с прогресс-барами:
🟢 зелёный — всё в норме, 🟠 оранжевый — близко к пределу, 🔴 красный — критическая нагрузка.
Ниже — интерактивные графики:
- Вкладки CPU / RAM / Диск / Сеть — динамика во времени
- Горизонтальные пунктирные линии — ваши пороги
- Heatmap CPU — наглядная матрица загрузки по часам и серверам
💡 Совет: наведите курсор на график — увидите точные значения!

## Анализ логов ##
Фильтруйте логи по:
- Серверам
- Уровням (INFO, WARNING, ERROR)
- Ключевым словам в сообщении
Сразу видите статистику:
- Круговая диаграмма распределения HTTP-статусов
Метрики: успешные/ошибочные запросы, среднее время ответа
Во вкладках:
- Популярные эндпоинты — топ-10 по количеству вызовов
- Ошибки — sunburst-диаграмма 4xx/5xx
- Производительность — самые медленные эндпоинты
📌 Внизу — кнопка «Экспорт в CSV» для дальнейшего анализа.

## Интеграционная аналитика ##
Выберите сервер — система автоматически сопоставит его метрики и логи.
Получите:
- Графики корреляции: загрузка CPU ↔ количество запросов, RAM ↔ время ответа
- Список инцидентов: моменты, когда высокая нагрузка совпала с 5xx-ошибками
- Рекомендации: топ медленных и проблемных эндпоинтов
Нажмите «Сгенерировать PDF-отчёт» — получите готовый документ для команды или отчёта!

## Генерация данных и управление ##
При первом запуске данные создаются автоматически в папке data/.
В боковой панели есть кнопки:
🔄 «Перегенерировать метрики»
🔄 «Перегенерировать логи»
— чтобы обновить синтетические данные без перезапуска.
## Экспорт и отчёты ##
- CSV — из модуля логов (для анализа в Excel/Tableau)
- PDF — из модуля интеграционной аналитики (готовый отчёт для руководства)
✅ Всё интерактивно, без перезагрузок, и работает локально!
Просто запустите streamlit run main.py — и начните исследовать вашу ИТ-инфраструктуру в пару кликов 🚀.
